**Como eu uso IA no desenvolvimento**

- 🧩 **Planejar antes de codar:** discuto a arquitetura e as decisões antes de gerar qualquer código
- 🔍 **Revisar tudo:** leio, testo e entendo cada trecho antes de ir para o repositório
- 🧪 **Testes como garantia:** peço testes junto com o código e rodo build, lint e testes antes de cada commit
- 📖 **Aprender no processo:** uso a IA para explicar conceitos novos, não só para entregar respostas
